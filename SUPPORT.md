# Support

Thanks for using URLPulse. Here is where to go depending on what you need.

## Reporting Bugs

Open a **bug report** issue: [new bug report](https://github.com/niranjansah87/Urlpulse/issues/new?template=bug_report.md). Include steps to reproduce, expected vs. actual behavior, and your environment.

## Requesting Features

Open a **feature request** issue: [new feature request](https://github.com/niranjansah87/Urlpulse/issues/new?template=feature_request.md). Describe the problem you are trying to solve, not only the proposed solution.

## Asking Questions

For questions and usage help, open a GitHub issue and label it as a question, or start a discussion if Discussions are enabled for the repository.

## Security Issues

Do **not** report security vulnerabilities through public issues. Follow the process in [`SECURITY.md`](./SECURITY.md).

## Documentation

Most questions about how URLPulse works are answered in the [documentation](./docs/README.md).
